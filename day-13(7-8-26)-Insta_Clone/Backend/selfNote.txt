we are starting with Route for post with get method
means we are making a new api with GET method

so what we are going to do in this : 

lets suppose we have 3 user 

user A ----------> 
               (GET /api/posts)
user B ----------> server
               (server need to send the post to that user only who req)
user C ---------->
(request to server to get there post)

And server will find the post in Database then send to that user

(a). POST /api/posts
       Gets JWT from cookies.
       Verifies the JWT.
       Gets the uploaded image from req.file.
       Uploads the image to ImageKit.
       Creates a MongoDB post with:
         caption
         img_url
         userId
       Returns the created post.

(b). GET /api/posts
       Gets JWT from cookies.
       Verifies the JWT.
       Finds posts belonging to that user.
       Returns those posts.
