And what access and refresh token is : 
normally have two tokens:
const accessToken = jwt.sign(
  { id: user._id },
  process.env.ACCESS_TOKEN_SECRET,
  { expiresIn: "15m" }
);

const refreshToken = jwt.sign(
  { id: user._id },
  process.env.REFRESH_TOKEN_SECRET,
  { expiresIn: "7d" }
);
             (a)Access Token                                
                   ↓
                Short lifetime
                   ↓
                Used to access protected APIs
                   ↓
                Example: 15 minutes

             (b)Refresh Token
                   ↓
                Long lifetime
                   ↓
                Used to get a new access token
                   ↓
                Example: 7 days
