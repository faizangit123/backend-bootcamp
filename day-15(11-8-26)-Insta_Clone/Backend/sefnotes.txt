User Auth ROUTER flow:

User sends username/email + password
            ↓
       Find user
            ↓
     User exists?
       ↓       ↓
      No       Yes
      ↓         ↓
    404     bcrypt.compare()
                ↓
          Password correct?
            ↓       ↓
           No       Yes
           ↓         ↓
          401    Create JWT
                     ↓
                Set cookie
                     ↓
                 200 OK

------------------------------------------
FOR USER POST ROUTER: 

(1) POST -> /api/posts -> createPostController 
    Flow : 
      Client
        ↓
      caption + image
  ↓      
      Express server
        ↓
      Get JWT from cookie
        ↓
      Verify JWT
        ↓
      Get user ID from JWT
        ↓
      Upload image to ImageKit
        ↓
      Get ImageKit URL
        ↓
      Create MongoDB post
        ↓
      Return post
--------------------------------------------
(2) GET -> all posts
    Logic flow:

       GET /api/posts
             ↓
       Check JWT cookie
             ↓
       Verify JWT
             ↓
       Get user ID from token
             ↓
       Find posts belonging to that user
             ↓
       Return posts
---------------------------------------------

(userId: decoder.id)
Logged-in user → decoder.id = 123
Database:
post A → userId: 123
post B → userId: 456
post C → userId: 123

response : post A and post C
----------------------------------------------

(3) GET -> user specific post & only that user post
    he logic is:

           Valid JWT
             ↓
           Get user ID
             ↓
           Get post ID from URL
             ↓
           Find post
             ↓
           Doesn't exist? → 404
             ↓
           Does post.userId === logged-in user ID?
             ↓
           No → 403
             ↓
           Yes → 200
